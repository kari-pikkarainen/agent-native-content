# Security Policy

## Supported versions

Agent-Native Content is a research reference implementation. Security fixes
are applied to the current `main` branch; older commits and published research
artifacts are not maintained as supported releases.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed
credential. Use GitHub's
[private vulnerability reporting](https://github.com/kari-pikkarainen/agent-native-content/security/advisories/new)
to share reproduction steps, affected commits, impact, and any proposed fix.

The maintainer will acknowledge a report as capacity permits, validate it
before assigning severity, and coordinate disclosure after a fix is available.
This project does not offer a bug bounty or a guaranteed response deadline.

Benchmark-methodology disagreements, incorrect research conclusions, and
ordinary correctness bugs are not security vulnerabilities; report those
through the public issue tracker unless disclosure would expose credentials or
private source material.

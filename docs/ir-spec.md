# Intermediate Representation Specification

The normalized intermediate representation will preserve document structure,
source provenance, text, tables, and token counts needed by retrieval
experiments. It will not contain embeddings, generated summaries, entities, or
other model-derived annotations.

The detailed schema will be defined during Milestone 3. Until then, the
authoritative requirements are in
[`benchmark-spec.md`](benchmark-spec.md#8-minimal-ir).
